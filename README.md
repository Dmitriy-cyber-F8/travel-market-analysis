# Анализ рынка отелей Москвы и Сочи

Пет-проект по анализу рынка краткосрочного размещения. Собраны данные по отелям из Ostrovok за два сезона (октябрь 2026, январь 2027) в двух городах - Москве и Сочи.

## О проекте

Туристический стартап планирует запуск продукта в сегменте бронирования отелей. Перед запуском нужно разобраться, как устроен рынок в Москве и Сочи: насколько сильна сезонность, чем отличаются города, какие факторы определяют цену за ночь.

Данные собраны самостоятельно через парсер Ostrovok на платформе Apify, очищены и проанализированы в Jupyter Notebook.

## Источники данных

- **Ostrovok** - данные по отелям через парсер `getascraper/ostrovok-hotels-scraper` на платформе Apify.
- **Объём:** 1110 отелей, 55 признаков (цена, рейтинг, категория, расстояние от центра, условия тарифов, координаты).
- **Срезы:** 2 города x 2 сезона.


## Стек

- **Python:** pandas, numpy, matplotlib, seaborn
- **Парсинг:** Apify (Ostrovok Scraper)
- **Данные:** Excel/CSV
- **Среда:** Jupyter Notebook


## Что сделано

**01_merge_clean.ipynb** - объединение 4 выгрузок из парсера в один датасет, добавление столбцов-источников (`source_city`, `source_season`), проверка и удаление дубликатов, приведение типов данных, анализ пропусков, добавление расчётных столбцов (`nights`, `price_per_night_calc`, `distance_category`, `rating_category`, `photo_count`).

**02_eda.ipynb** - разведочный анализ: распределения цен, рейтингов, категорий и расстояний; базовые метрики по городам и сезонам; корреляционный анализ; проверка пропусков в сегментах; формулировка гипотез.
